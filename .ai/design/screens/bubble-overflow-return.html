Overflow bubble returns to the stack

When the person closes a bubble in the stack, the newest overflow bubble comes back with no sound, no heads-up row, no flyout and no expansion. Android draws all of this; Lynket only posts the notification again. The stack size is illustrative. The row of tiles shows the stack as Android draws it when expanded.
